Create your own game

A game is one LaTeX file. You start from a template, load it on the host page, and play. The same file also prints as a study sheet or an answer key.

Getting started

  1. Download the template. It’s a .zip of one folder holding:
    • template.tex, the game file. It’s a complete, playable game (the Starter Game on the host page) in which each clue shows one feature, with a comment saying which. You replace its clues with your own.
    • calculatedrisk.sty, the style file that lets LaTeX turn the game into a PDF. Leave it as it is, next to the game file.
    • Two example pictures, used by two of the clues. Delete them when you no longer need them.
  2. Fill in the clues. Unzip the folder, rename it and the .tex file if you like (say, calc1-review/calc1-review.tex), and edit it in any LaTeX editor or plain text editor. To use Overleaf, choose New Project → Upload Project and upload the .zip as it is.
  3. Load it on the host page. On the host page, drop the file (or the zipped folder, if the game has pictures) on Your own game. The app checks the file, lists any problems with their line numbers, and lets you preview every clue before class.

You don’t need LaTeX installed to play. The app reads the file itself. LaTeX is only for making PDFs.

The game file

A game file has three parts: a few setup lines at the top, the categories, and Fermat’s Last Round at the end. Here is a whole game, shortened.

% 1. Setup
\documentclass{article}
\usepackage[solutions]{calculatedrisk}  % which PDF to print
\gametitle{Calculus I Review}           % shown on the board
\newcommand{\dd}[1]{\frac{d}{d#1}}   % your macros (optional)

\begin{document}

% 2. Five or six categories, five clues each
\begin{category}{Derivatives}       % the category name

  \begin{clue}[say]                 % the 100 clue
    It is the derivative of $x^3.$   % what the class sees
  \response
    What is $3x^2$?                  % the correct response
  \solution
    By the power rule, $\dd{x} x^n = n x^{n-1}.$  % optional
  \end{clue}

  \begin{clue}                      % the 200 clue
    ...
  \response
    ...
  \end{clue}

  % ... the 300, 400 and 500 clues
\end{category}

% ... more categories

% 3. Fermat's Last Round
\begin{final}{Series}
  It is the value of $\sum_{n=1}^\infty \frac{1}{n^2}.$
\response
  What is $\pi^2/6$?
\end{final}

\end{document}
\usepackage[solutions]{calculatedrisk}
Loads the style file. The word in brackets only affects the PDF (see Printing handouts); the game ignores it.
\gametitle{...}
The title shown on the board and the host screen.
\begin{category}{Name} ... \end{category}
One column of the board. Keep names short so they fit at the top of the column.
\begin{clue} ... \end{clue}
One square. Inside it: the clue, then \response and the correct response, then optionally \solution and a worked solution.

Anything after a % is a comment, ignored by both the app and LaTeX. That makes it easy to keep spare clues in the file: put % in front of each of their lines.

Writing clues

  • Five or six categories, five clues each. The app won’t start a game with a different number.
  • Values come from the order. The first clue in a category is worth 100, the second 200, and so on up to 500. To change a clue’s value, move its whole \begin{clue} … \end{clue} block up or down.
  • Clues are answers, responses are questions. Write the clue as a statement (“It is the derivative of x³.”) and the response as a question (“What is 3x²?”).
  • The response is for you. It shows on your host screen during the clue, and on the board after a correct answer, depending on the setting you choose.
  • The solution is optional. Use it for worked steps you’d like to show the class after the response. align* works well here.

Clue options

Put options in square brackets after \begin{clue}, separated by commas, as in \begin{clue}[doubledown, write].

OptionWhat it does
doubledown Makes the clue a Double Down. Before the clue appears, you choose the team that picked it and enter its wager. The board doesn’t mark Double Down squares, but your host screen does. One or two per game is typical.
write Shows a large “Write it” banner: teams write their response before ringing in. Good for long expressions.
say Shows a large “Say it” banner: teams can just say the response, like “What is 6?”

A clue without write or say shows no banner.

Fermat’s Last Round

The last part of the file, after the categories, is one final clue:

\begin{final}{Series}
  It is the value of $\sum_{n=1}^\infty \frac{1}{n^2}.$
\response
  What is $\pi^2/6$?
\end{final}

The board shows only the category at first. Each team wagers some of its points, then you show the clue, and every team writes a response. A \solution works here too, and so do [write] and [say], as in \begin{final}[write]{Series}. The final round is optional; the app reminds you if it’s missing.

Math and text

Write math the way you always do: $...$ or \(...\) inline, and \[...\] or environments like align* for displays. On the board, long equations shrink to fit the screen, but two short lines read better than one long one.

Your macros. \newcommand and \DeclareMathOperator lines at the top of the file work inside math. If you keep your macros in your own package, such as \usepackage{mymacros}, put mymacros.sty in the game’s folder and load the zipped folder; the app reads its macros too.

Text. Outside math, the app understands the common formatting commands:

  • \textbf, \emph, \textit, \texttt, \underline, and \textcolor{red}{...} with named colors
  • itemize, enumerate, and center
  • \\ for a line break, a blank line for a new paragraph, and \$ for a dollar sign
  • quotes (``...''), dashes (--, ---), and accents

Anything else is listed when you load the file, so you can fix it before class.

Pictures

Add a picture anywhere in a clue, response or solution with

\includegraphics[height=4cm]{region.png}
  • Keep the image in the same folder as the game file.
  • Use PNG or JPG; both work in the game and in the PDF. (Browsers can’t show PDF images, and pdflatex can’t use SVG.) A name without an extension (region) finds region.png or region.jpg.
  • Options like [height=4cm] or [width=0.5\textwidth] only set the size in the PDF. On the board, the text goes on the left and the picture on the right, sized to fit the screen.
  • To load a game with pictures, zip its folder and load the .zip (see below).

Loading your game

On the host page, under Choose a game, drop your file on Your own game, or click it to choose the file.

Your game hasLoad
Only text and math The .tex file
Pictures, or its own .sty file of macros A .zip of the game’s folder. On a Mac, right-click the folder and choose Compress; on Windows, right-click and choose Send to → Compressed (zipped) folder. You can also select the .tex file and its pictures together.
Written in Overleaf The .zip from Overleaf’s Menu → Download → Source

The app finds the game file and its pictures in the .zip and ignores everything else (PDFs, LaTeX’s extra files, TikZ sources, and calculatedrisk.sty). Your files stay on your computer; nothing is uploaded.

Check it before class. After loading, the host page shows the game’s title and size, or a list of problems with their line numbers. Fix any problems and load the file again. Then click Preview every clue and response to read through everything as it will appear.

Printing handouts

Compile the game file with LaTeX (pdflatex, xelatex, or Overleaf) to get a PDF. The word in brackets on the \usepackage[...]{calculatedrisk} line chooses what it contains:

OptionThe PDF contains
questionsThe clues only, such as a study sheet for students
answersThe clues and responses, after an overview of the board
solutionsThe clues, responses and worked solutions, after an overview of the board. The best one to proofread while you write.

You can add these after it, separated by commas, as in \usepackage[solutions, writesay]{calculatedrisk}:

writesayMarks each clue’s [write] or [say]. Handy while writing; leave it off for copies you give students.
boardAlways shows the board overview, even with questions
noboardNever shows the board overview

The PDFs never reveal which clues are Double Downs.

Tips

  • Keep most clues quick. A board has 25 or 30 clues, so a few long ones are fine, but most should take under a minute. One way to make a clue quicker is to ask for one step: the u and dv for an integration by parts, instead of the whole integral.
  • Go up in difficulty. Put the easiest clue first in each category, since it’s worth 100.
  • Mark long responses [write]. It saves arguments about who said what first.
  • Start from a built-in game. Each game on the host page has a Download link. Its file is a good example to copy from.
