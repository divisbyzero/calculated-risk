% Jeopardy game template.
%
% Each game lives in its own folder inside games/, with its pictures:
%   games/jeopardy.sty            (shared by every game)
%   games/my-game/my-game.tex
%   games/my-game/figure.png
% Copy this template folder, rename it and the file, and fill in the
% clues. \usepackage{../jeopardy} below finds the shared jeopardy.sty one
% folder up. (pdflatex warns that the package "provides jeopardy"; that
% warning is harmless.) To list the game in the app, add it to
% games/index.json.
%
% Rules:
%   * 5 or 6 categories, each with exactly 5 clues.
%   * Clues are worth 100, 200, 300, 400, 500 in the order they appear.
%     To reorder, just move the \begin{clue} ... \end{clue} blocks.
%   * Each clue is: the clue, then \response, then the correct response.
%   * Optionally add \solution after the response, followed by worked steps.
%     After a correct answer, the board can show the response and solution.
%   * Mark a Daily Double with \begin{clue}[dailydouble].
%   * Optional: mark a clue [write] if players must write the response
%     before ringing in, or [say] if they can just say it. The board shows
%     a large icon for it. Combine options with commas:
%     \begin{clue}[dailydouble, write]. Final Jeopardy takes it too:
%     \begin{final}[write]{Category}.
%   * Pictures: \includegraphics[height=4cm]{figure.png} anywhere in a
%     clue, response or solution. Put the file in this game's folder and
%     use PNG or JPG. The board shows the picture to the right of the text.
%   * Saving in VS Code builds two PDFs: the answer key and study questions.
%   * Math works inside $...$, \(...\), \[...\], and environments like align*.
%   * \newcommand and \DeclareMathOperator macros defined below work
%     inside math.
%   * In text you can use \textbf, \emph, \textit, itemize, enumerate, \\,
%     and \$ for a dollar sign.
