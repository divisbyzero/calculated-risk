How it works

Two windows: one on your computer, one on the projector.

  1. 1

    Choose a game

    Play a ready-made game or upload one you created.

  2. 2

    Put the game board on the projector

    Connect your computer to the projector with it set as a secondary display (not mirrored). Open the game board window, drag it onto the projector, and make it full screen.

  3. 3

    Run the game from your computer

    Select a clue on the host screen to reveal it on the game board, mark responses right or wrong, and see the scores update automatically.

Create your own game

A game is a single LaTeX file: five or six categories of five clues, plus a final clue.

  1. Download the template. A small working game that shows every feature, plus the style file that prepares a PDF.
  2. Customize your game. Fill in the categories, clues, images, responses, and optional worked solutions.
  3. Load it on the host page. The app checks the file and lets you preview every clue.
  4. Play the game with your students!

\usepackage[solutions]{calculatedrisk}

  \response
    What is $1$?
  \solution
    $\int_0^1 3x^2\,dx = x^3\big|_0^1 = 1.$
  \end{clue}

\end{category}

Questions

What do I need?

A computer and a projector (or any second screen), and a current version of Chrome, Edge, Firefox, or Safari. The math typesetting loads from the internet, so you’ll need a connection.

Do students need to do anything?

No. They watch the projector and answer out loud or on paper.

Is my game file uploaded anywhere?

No. Your browser reads the file on your computer. Nothing is sent to a server.

What if I close the tab in the middle of a game?

The game saves itself as you play. Open the host page again and choose Resume game.

My projector shows the same thing as my computer. What do I change?

Your display is set to mirror, so the class would see your host screen, answers included. Switch it to extend: on a Mac, open System Settings → Displays and turn off mirroring; on Windows, press Windows + P and choose Extend.

How do I make a handout from a game?

Compile the game’s .tex file with LaTeX. Change the option on the \usepackage[…]{calculatedrisk} line to questions for a study sheet, answers for an answer key, or solutions for answers with worked solutions.
