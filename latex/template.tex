% Jeopardy game template.

% to compile it with pdflatex to get a printable answer key.
%
% Rules:
%   * 5 or 6 categories, each with exactly 5 clues.
%   * Clues are worth 100, 200, 300, 400, 500 in the order they appear.
%     To reorder, just move the \begin{clue} ... \end{clue} blocks.
%   * Each clue is: the clue, then \response, then the correct response.
%   * Optionally add \solution after the response, followed by worked steps.
%     After a correct answer, the board can show the response and solution.
%   * Mark a Daily Double with \begin{clue}[dailydouble].
%   * Math works inside $...$, \(...\), \[...\], and environments like align*.
%   * \newcommand macros defined below work inside math.
%   * In text you can use \textbf, \emph, \textit, itemize, enumerate, \\,
%     and \$ for a dollar sign.
